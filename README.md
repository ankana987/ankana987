I'm a Computer Science Engineering student who is currently exploring the world of software development and trying to figure out where I fit best in this huge tech ecosystem.

My journey started with Frontend Development, where I learned and worked with HTML, CSS, JavaScript, and React. I enjoy turning ideas into functional and interactive web applications and experimenting with different designs, components, and technologies.

Right now, I'm taking the next step in my journey by learning Backend Development. I'm exploring how servers, APIs, databases, authentication, and the logic behind web applications actually work. My goal is to become someone who can understand and build applications from both the frontend and backend side.
Alongside development, I'm also working on improving my problem-solving and Data Structures & Algorithms skills. I believe that becoming a good developer isn't just about knowing frameworks — it's also about understanding how to think, solve problems, and build things that actually work.

🌱 I'm still learning, still experimenting, and definitely still making a lot of mistakes. Some days I build something I'm proud of, and some days I spend hours trying to understand why one line of code broke everything . But that's part of the journey.
